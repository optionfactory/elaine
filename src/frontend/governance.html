Framework assessment coverage

How far the regulatory assessment has progressed across the repositories that declare compliance data in their elaine.yaml. Each framework is tracked per repository as either assessed (including explicit out-of-scope verdicts: deciding something does not apply is itself an assessment) or pending. Repositories without a manifest are not counted in the coverage percentage; bring them into the audit process first, then use this page to find the frameworks where assessments are still missing.

Stewardship recap

Stewardship load across the live repositories that declare stewards in their elaine.yaml. Repositories looked after by several stewards count once under each of them, so Projects measures assignments rather than unique repositories. Tier 1/2 counts the projects carrying an SLA and Active the ones with an active lifecycle: together they hint at how much operational weight sits on each person. Rows are sorted by active project count, descending. Repositories declaring no steward are not listed — an unowned project is nobody's problem, which is exactly the problem.

Repositories by inactivity

Time since the last push for live repositories with no activity in the last 60 days. Repos receiving no commits for 6+ months are likely neglected: dependencies stop receiving updates, knowledge evaporates, and nobody notices when something breaks. Compare the age with the declared lifecycle: an active project that is a year stale is a red flag, while an end-of-life or unmaintained one being stale is expected.
