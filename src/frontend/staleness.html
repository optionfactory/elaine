Dashboard Staleness Compliance Risk Matrix

Repositories by inactivity

Time since the last push for every live repository. Repos receiving no commits for 6+ months are likely neglected: dependencies stop receiving updates, knowledge evaporates, and nobody notices when something breaks. Compare the age with the declared lifecycle: an active project that is a year stale is a red flag, while an end-of-life or unmaintained one being stale is expected.
