Declared domains and exposure

One row per domain declared in the environments section of a repository's elaine.yaml, with the ingress exposure and certificate management style of the environment serving it. Only repositories with a manifest declaring environments appear here: as manifest coverage grows, this becomes the organization-wide domain inventory.

Toolchains

Toolchains detected by the scanners across live repositories. A repository appears once per toolchain it ships code for, so polyglot repositories count multiple times; the total is the number of toolchain-repository pairs, not repositories. Repositories whose scanners failed are not counted: their toolchains are unknown, not absent.

Repositories by tier

Live repositories that declare an operational tier in their elaine.yaml, sorted by tier then name. Deciding that a project is tier4 (experimental) is itself an assessment, so repositories with no declared tier are not listed: classify them first, then look for your project here.

Repositories by steward

One row per stewardship assignment across the live repositories, sorted by steward name. Use the filter to narrow the table down to rows matching a steward or a repository name. The aggregated recap by steward lives on the Governance page.
